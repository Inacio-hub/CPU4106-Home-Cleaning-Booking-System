- evidence/audit_2026_10_26: historical isolated Linux audit, before/after logs, corrective diff and screenshots. Expanded audit: 18 passing, 9 failing before fixes; all 27 passing after. The baseline visibility screenshot deliberately shows an old defect.
- evidence/windows: supplied corrected-release Windows evidence. audit_complete_output.log and audit_exit_code.txt record 27 passing tests in 14.064 seconds, exit 0. The root has three screenshot states and resumed_browser has eight more: eleven genuine states in total. These are not eleven additional automated cases.
- Windows captures document invalid address, saved request, overlap rejection, hidden pending request, allocation, assigned visibility, start, completion, cancellation fixture, cancelled customer view and hidden cancellation.
- RESULTS_NOTE.txt preserves historical interruption text below its later completion update. The completion update supersedes the earlier browser-blocked status. Server stopped after collection; historical localhost URLs are not active deployment links.
- Source bytes in this package match the six tested source files in the Windows archive. Fictional records only; runtime databases and password hashes are excluded.
- Existing Linux browser checks, automated suites and screenshot counts are distinct; do not sum repeated runs or inherited test cases.
- Blank CSV files are templates. No independent user acceptance, meeting, feedback or individual authorship is established by their presence.
- A fresh packaging check, if run, is recorded separately in evidence/packaging_check. It does not replace or alter the historical Windows result.
